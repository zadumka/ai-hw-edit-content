# ai-hw-edit-content

Щотижневий звіт про те, наскільки ментори правлять відгуки, які AI пише на домашні завдання GoIT. Звіт рахується по курсах і модулях і порівнюється з цілями.

Звіт збирає Claude за сценарієм `ai-hw-mentor-edits-report` у конекторі LMS_MCP: «зроби звіт по правках менторів за тиждень». Цей репозиторій містить код і словник векторів, тож повна модель fastText (4,5 ГБ) не потрібна.

## Що всередині

| Шлях | Що це |
| --- | --- |
| `data/uk-hw-vectors-v1.npz` | Словник векторів з `cc.uk.300.bin`: 110 556 слів + 152 010 n-грам, int8, 72 МБ |
| `hwreport/text.py` | Очищення тексту, як `to_plain_text` у ноутбуці `analytics (1).ipynb` |
| `hwreport/vectors.py` | Вектори слів: зі словника, а для нових слів — середнє n-грам (правило fastText) |
| `hwreport/compute.py` | CSV вивантаження → схожість кожного відгуку → `agg.json` |
| `hwreport/dashboard.py` | `agg.json` → HTML-дашборд за правилами `report-assistant` |
| `hwreport/courses.json` | Курси, їхні id, напрями і цілі |
| `tools/build_vectors.py` | Перезбирає словник з повної моделі |

## Запуск

```bash
pip install -r requirements.txt
python -m hwreport.compute hw-edits.csv out/
python -m hwreport.dashboard out/agg.json out/index.html --start 2026-11-09 --end 2026-11-15
```

CSV — це результат запитів зі сценарію LMS, по одному курсу, сторінками по 200 рядків. Якщо в CSV є курс, якого немає в `courses.json`, `compute` зупиниться і назве його.

## Точність

Схожість рахується за формулою ноутбука:

`(50 × (cos TF-IDF + 1) + clip(100 × (1 − WMD / 3), 0, 100)) / 2`

TF-IDF навчається окремо на кожному курсі.

Перевірку зроблено на тижні 9–14.11.2026: 13 курсів, 79 модулів, 9 601 відгук. Порівнювали з повною моделлю, і слова цього тижня навмисно вилучили зі словника, щоб змоделювати новий тиждень. Найбільша різниця середньої схожості модуля — 0,035 пункту, курсу — 0,01. Погоджена допустима межа — 0,13 пункту на модуль.

## Як оновити словник

Якщо з'являться курси з новою лексикою, словник можна перезібрати на машині з моделлю:

```bash
python tools/build_vectors.py cc.uk.300.bin.gz tokens.json data/uk-hw-vectors-v2.npz
```

Після цього треба оновити `DEFAULT_PATH` у `hwreport/vectors.py`.
